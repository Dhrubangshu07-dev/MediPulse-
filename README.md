## 🚀 Features
*   **Patient Portal:** Dedicated login and dashboard for patients.
*   **Modern UI:** Responsive and modern user interface built with Tailwind CSS.
*   **Robust Backend:** Powered by Node.js and structured with custom routes and middleware.
*   **Database Management:** Seamless database integration and ORM using Prisma.

## 🛠️ Tech Stack
*   **Frontend:** HTML, JavaScript, React (JSX), Tailwind CSS, Vite
*   **Backend:** Node.js, Express.js (implied)
*   **Database/ORM:** Prisma
*   **Tools:** npm, PostCSS

## 📂 Project Structure
*   `/src` - Contains the main frontend source code and React components (e.g., `MediPulse.jsx`).
*   `/routes` - Backend API route definitions.
*   `/middleware` - Custom middleware for the backend server.
*   `/prisma` - Database schema and Prisma configuration.
*   `/lib` & `/data` - Utility functions and static data.
*   `server.js` - Main entry point for the backend server.
*   `index.html`, `landing.html`, `patient_login.html` - Core HTML templates.

## ⚙️ Prerequisites
Make sure you have the following installed on your local machine:
*   [Node.js](https://nodejs.org/) (v14 or higher)
*   npm (comes with Node.js)
*   A relational database (e.g., PostgreSQL, MySQL) supported by Prisma.
